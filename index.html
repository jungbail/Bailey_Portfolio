Movie Watchlist Planner

A Java desktop application that lets users browse a movie catalog, search and filter titles, build a personal watchlist, and export their selections — built with MVC architecture and TMDB api integration for live movie data.

  • Search, filter, and sort movies by genre, title, rating, and date
  • Build and persist a custom watchlist
  • Export watchlist data for sharing or backup
  • Designed with UML diagrams and comprehensive unit tests
  • If movie is not in the database, the user can look it up with an api call
